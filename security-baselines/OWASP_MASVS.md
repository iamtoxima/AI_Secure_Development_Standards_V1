# OWASP MASVS Baseline

Verified: 2026-08-12

OWASP MASVS is the mobile application security verification standard. OWASP
also provides MASTG and related mobile testing resources.

Use MASVS/MASTG to review mobile-security requirements in areas such as:

- secure storage;
- cryptography;
- authentication;
- network communication;
- platform interaction;
- code quality/tampering;
- privacy.

## Rule

For a release claiming MASVS alignment:

- record the referenced MASVS version/control groups;
- perform actual verification/testing;
- use MASTG or equivalent evidence;
- do not claim compliance solely because `mobile-security/SKILL.md` is active.
