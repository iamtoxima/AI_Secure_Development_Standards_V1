# OWASP API Security Baseline

Verified: 2026-08-12

At the verification date, OWASP's current API Security Top 10 edition is 2023.

Use it as an awareness/checklist source for API design and testing, particularly
for:

- broken object-level authorization;
- authentication;
- object property/mass-assignment exposure;
- resource exhaustion;
- function-level authorization;
- sensitive business flows;
- SSRF;
- security misconfiguration;
- API inventory;
- unsafe consumption of external APIs.

The repository's `api-security`, `security`, `performance`, and `resilience`
Skills should implement the engineering principles rather than repeatedly
loading the Top 10 document.
