# OWASP ASVS Baseline

Verified: 2026-08-12

The OWASP Application Security Verification Standard (ASVS) is used as a
requirements/verification reference for application security.

At the verification date, OWASP lists ASVS 5.0.0 as the latest stable version.

## Use

Do not load the entire ASVS into every coding task.

Use it to:

- check whether the repository's security Skills omit a relevant control family;
- build security requirements for high-risk products;
- build release/security verification checklists;
- reference requirement identifiers in formal security work when useful.

## Project Rule

If a project claims alignment with a specific ASVS version/level:

- record the version;
- map applicable controls;
- retain verification evidence;
- do not claim ASVS compliance merely because this standards repository was used.
