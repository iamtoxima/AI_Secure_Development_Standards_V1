# NIST SSDF Baseline

Verified: 2026-08-12

NIST SP 800-218, Secure Software Development Framework (SSDF) Version 1.1,
remains the current final SSDF publication at the verification date.

NIST published SSDF Version 1.2 as an Initial Public Draft in December 2025.
Do not treat a draft as a finalized mandatory replacement without checking its
status.

## Use

The repository uses SSDF as a secure-development-lifecycle reference for:

- preparing the organization/project for secure development;
- protecting software/components;
- producing well-secured software;
- responding to vulnerabilities;
- supply-chain awareness;
- verification and root-cause remediation.

## AI Systems

NIST SP 800-218A is a final community profile augmenting SSDF for generative AI
and dual-use foundation model development.

Use it as additional context for projects that actually develop AI models or
high-risk AI systems; it is not necessary for every application that merely
calls an LLM API.
