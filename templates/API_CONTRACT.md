# API Contract

Use the project's existing response conventions. Do not invent a new envelope unnecessarily.

## Common Rules

- Authentication requirements are explicit.
- Authorization requirements are explicit.
- Request size/content-type constraints are explicit when relevant.
- Error codes are safe and stable where practical.
- Sensitive data is not returned by default.
- Request/correlation ID behavior is documented where used.
