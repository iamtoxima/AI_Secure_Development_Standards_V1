|---|---|---|---|---|

## Milestone Rule

A milestone is not complete until:

- implementation is coherent;
- affected docs are updated;
- relevant tests/checks have run;
- unresolved risks are recorded;
- a stable Git checkpoint is created when appropriate.

Do not combine unrelated milestones merely to reduce the number of prompts.
